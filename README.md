# KL Attendance Calculator

A free web app for KL University (KLEF) students to calculate 
weighted LTPS attendance, check 85% exam eligibility, plan safe 
bunks, and sync attendance from KL University NewERP.

## Features

- LTPS weighted attendance calculator (Lecture/Tutorial/Lab/Skill)
- 85% exam eligibility and 75% detention threshold checker
- Bunk Planner — simulate safe class skips
- NewERP sync — import attendance automatically
- KL University attendance rules guide
- Condonation eligibility checker

## Live Tool

👉 **[kluattendancecalc.vercel.app](https://kluattendancecalc.vercel.app)**

Free for all KL University students at Vaddeswaram and Hyderabad campuses.

## About

Built for KL University students who are tired of manually 
calculating LTPS weighted percentages and guessing how many
